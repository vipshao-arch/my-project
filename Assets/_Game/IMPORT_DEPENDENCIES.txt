====================================================================
 test09 工程 —— 导入前必读：Package 依赖清单 + 合并指引
====================================================================

【为什么报错】
本 unitypackage 只含 Assets 资产，【不包含 Package】。
下面两个包必须手动加进新工程的 Packages/manifest.json，
否则导入后报 40+ 个错误：

  error CS0234: 'Netcode' does not exist in namespace 'Unity'
  error CS0246: 'NetworkBehaviour' / 'NetworkVariable' / 'NetworkManager' 找不到

====================================================================
【最简操作：复制这两行，粘贴到 "dependencies" 花括号内】
====================================================================

打开新工程 Packages/manifest.json，形如：

    {
      "dependencies": {
        ... 把下面两行粘贴到这里 ...
      }
    }

要粘贴的两行（每行末尾的逗号是必须的，别漏）：

      "com.unity.netcode.gameobjects": "1.9.1",
      "com.unity.ai.navigation": "1.1.7",

保存后回到 Unity，会自动下载编译，报错消失。

====================================================================
【JSON 逗号规则（报 "is not valid JSON" 就是这里错了）】
====================================================================

JSON 里每个条目末尾必须跟【逗号】，但【最后一条】末尾不能有逗号。

  ✗ 错误（少逗号）：
      "com.unity.netcode.gameobjects": "1.9.1"
      "com.unity.ai.navigation": "1.1.7"

  ✓ 正确（每条末尾逗号）：
      "com.unity.netcode.gameobjects": "1.9.1",
      "com.unity.ai.navigation": "1.1.7",

  ✗ 错误（最后一条多了逗号）：
      "com.unity.ai.navigation": "1.1.7",

  ✓ 正确（最后一条无逗号）：
      "com.unity.ai.navigation": "1.1.7"

====================================================================
【完整可用示例】
====================================================================

{
  "dependencies": {
    "com.unity.netcode.gameobjects": "1.9.1",
    "com.unity.ai.navigation": "1.1.7",
    "com.unity.collab-proxy": "2.12.4",
    "com.unity.textmeshpro": "3.0.7",
    "com.unity.ugui": "1.0.0"
  }
}

注意：
  - "dependencies" 花括号内最后一个条目（如上例 ugui）后面【不要】加逗号。
  - 如果你原有 manifest 里已有其他包，保留它们，把上面两行插入到
    "dependencies" 开头（第一行之前），并保证原有条目之间的逗号不被破坏。
